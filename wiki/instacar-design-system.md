# instacar-design-system

**Summary**: This guideline outlines the comprehensive visual language for the InstaCar platform, focusing on a high-contrast, energetic aesthetic driven by vibrant orange accents within a professional, clean foundation suitable for an automotive marketplace.
**Context**: [instacar] or [concepts]
**Sources**: instacar.gr-DESIGN.md
**Last updated**: 2026-06-19

***

## Overview
This system is built around speed, energy, and high contrast to support the rapid decision-making required for leasing and buying vehicles (source: instacar.gr-DESIGN.md). The core design principle is balancing commercial urgency (`#FF6500` orange) with professional credibility using generous whitespace and structured layouts (source: instacar.gr-DESIGN.md).

## Key Components of the System
*   **Color Palette**: Defined roles for Primary, Accent, and Neutral colors guiding all visual choices (see [[instacar-color-palette]]).
*   **Typography**: Uses Proxima Nova with a rigid weight and size hierarchy to maintain clarity over stylistic flair (see [[instacar-typography]]).
*   **Components**: Provides pixel-perfect styles for key UI objects like Buttons, Product Cards, and Input Fields (see [[instacar-component-library]]).
*   **Layout Principles**: Establishes concrete rules for spacing (`4px` base unit), grid structures, and mobile responsiveness across breakpoints (source: instacar.gr-DESIGN.md).

## Do's & Don'ts (Summary)
*   **Do:** Use orange sparingly for primary CTAs and pricing emphasis. Maintain generous vertical spacing to prevent cognitive overload ( source: instacar.gr-DESIGN.md).
*   **Don't:** Never use color alone to convey status; always combine with text or icons. Do not treat the design as a purely modern flat aesthetic and reduce line-height below `1.25×` (source: instacar.gr-DESIGN.md).
