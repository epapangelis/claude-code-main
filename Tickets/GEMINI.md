# Ticket Creation Instructions

These instructions apply to all files in the `Tickets/` directory.

## Linear Ticket Structure
All tickets created as markdown files here MUST follow this structure:

```markdown
# Description
[_Short description of the task or issue_]

# What we currently do
[_Current implementation, screenshots/looms_]

# What to do
[_Detailed description of technical requirements_]

# Acceptance Criteria
**Given** ... **When** ... **Then** ...

# Figjam
[_Flowchart link/placeholder_]

# Figma
**Desktop**: ... **Mobile**: ...

# Metrics
[_Success measures_]

## Notes
[_Comments, user stories, resources_]
```

## Default Linear Fields
- **Assignee:** Evangelos (me)
- **Team:** product
- **Status:** Ready for Tech
