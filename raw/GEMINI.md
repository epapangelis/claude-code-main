# Raw Source Instructions

These instructions apply to all files in the `raw/` directory.

## Core Mandates
- **Immutable:** NEVER modify, move, or delete files in this directory.
- **Ingest Only:** Files here are source material for the wiki.
- **Tracking:** Before processing a file, check `wiki/log.md` to ensure it hasn't been ingested already.
- **Organization:** 
  - `raw/instacar/` for company-related files.
  - `raw/blog/` for personal blog sources.
  - `raw/personal/` for hobbies and experiments.
